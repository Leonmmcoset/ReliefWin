# ReliefOffice installation and removal

The bootcd stores the seven applications, the ReliefMath renderer, its STIX math font and maintenance files under deployment/ReliefOffice. Its dedicated txtsetup.sif maps that source tree to the target's Program Files/ReliefOffice through the existing installation copy queue. The preinstall image keeps the files directly in Program Files/ReliefOffice and uses the original setup tree mappings. The Live environment may carry the offline deployment payload in RAM; it has no installed Office directory, registration or Start menu shortcuts. LiveCD initialization never registers the suite.

After creating the installed user profiles, syssetup reads the target registry's ProgramFilesDir, opens reliefoffice.inf from that directory and assigns custom DIRID 32768 to the suite directory. Its DefaultInstall section registers the uninstall entry, suite-specific document types and seven common Start menu shortcuts. Existing extension defaults are preserved by FLG_ADDREG_NOCLOBBER. There are no desktop shortcuts. The target-system path runs after registry and drive redirection, so HKLM operations apply to the installation being configured.

The maintenance program validates that its own directory matches the registered InstallLocation. It deletes only the checked-in manifest, including the renderer and bundled font. It never enumerates or recursively deletes user directories. If an application file is in use or another removal step fails, it returns an error and retains the uninstall entry and maintenance executable for retry. Each missing manifest file counts as already removed. A shortcut is removed only if its stored target matches the corresponding installed executable. An association is removed only if its command still points to that executable, and an extension's default value is cleared only if it still names the suite's own ProgID. The uninstall registration is removed before the running maintenance executable is scheduled for deletion at restart. If scheduling fails, the known uninstall values are restored so the installed maintenance executable remains available for retry. Removing a nonempty suite directory is allowed to fail, preserving extra files and documents stored there.

The image file-security policy gives ReliefOffice directories and files the existing CREATEDDIR and CREATEDFILE application permissions: Administrators and SYSTEM have full access, while ordinary users retain read and execute access. These specific rules override the protected-component defaults for Program Files. The preinstalled images and a new installation on a formatted volume apply the complete policy. An upgrade applies it only to the inventory's installed files; the Office directory entries are not in that inventory. A new installation without formatting currently applies explicit policy only to the Windows tree, so Office permissions on that path depend on inheritance and require separate installation validation.

The contracts come from the Windows SDK headers and the following Microsoft documentation:

- [SetupInstallFromInfSectionW](https://learn.microsoft.com/en-us/windows/win32/api/setupapi/nf-setupapi-setupinstallfrominfsectionw): SPINST_REGISTRY and SPINST_PROFILEITEMS select registration and shortcuts without a copy queue.
- [SetupSetDirectoryIdW](https://learn.microsoft.com/en-us/windows/win32/api/setupapi/nf-setupapi-setupsetdirectoryidw): a custom DIRID at or above DIRID_USER maps to a concrete directory for that INF handle.
- [Using Dirids](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/using-dirids): 32768 is the first user-defined directory ID. The installer and INF use that same ID; 66000 is resolved as a printer-driver directory by this SetupAPI implementation.
- [INF ProfileItems directive](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/inf-profileitems-directive): Name with no current-user flag selects all users; SubDir chooses a submenu under Start/Programs.
- [INF AddReg directive](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/inf-addreg-directive): FLG_ADDREG_NOCLOBBER preserves an existing value.
- [MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw): MOVEFILE_DELAY_UNTIL_REBOOT permits deleting the running program after restart on a local volume.
- [IShellLinkW::GetPath](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishelllinkw-getpath): SLGP_RAWPATH returns the stored link target for ownership checking.
