# ReliefWin branding

ReliefWin is the name of this modified operating system. It is derived from LiberNT and ReactOS; it is not an official build of either upstream project.

The ReliefWin logo was supplied by the maintainer for this rebranding. The original input is `media/graphics/branding/reliefwin-source.jpg`. Generated resources preserve its proportions and colours. No ownership of upstream trademarks or artwork is claimed.

The GPL licences apply to source code as specified in each file. Supplying an image for this project does not by itself grant a separate public artwork licence. Contact the maintainer before reusing the ReliefWin artwork outside this project.
