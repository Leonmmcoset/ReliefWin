# Fluent caption button assets

Run `PYTHONDONTWRITEBYTECODE=1 python3 captionbuttons_fluent.py` in this directory
to regenerate the eight `NORMAL_` and `LIGHT_` close, minimize, maximize and
restore BMP strips. The default output directory is resolved relative to the
script, so it also works from the repository root. Pillow and CairoSVG are the
only Python dependencies. `--check` compares the actual checked-in files with
the generated bytes without writing. An optional positional directory selects
another output directory; it must already exist.

The checked-in raster output was generated with CairoSVG 2.9.1, Cairo 1.16.0
and Pillow 9.0.1. The SVG hashes and `--check` detect input or renderer drift.

Each strip is a bottom-up BITMAPV4HEADER BMP with 32-bit BGRA pixels and explicit
channel masks, 46 pixels wide and 256 pixels high. Every pixel is opaque. The
eight 46 x 32 cells follow the theme state order: active normal, hot, pressed,
disabled, then inactive normal, hot, pressed, disabled. Only the four regular
caption controls are generated; tool-window close, help and MDI controls retain
their separate assets and glyphs.

The icons are the genuine 16-pixel regular Microsoft Fluent UI System Icons
recorded in [fluentui-system-icons/SOURCE.txt](fluentui-system-icons/SOURCE.txt).
Each source SVG remains byte-for-byte unchanged. CairoSVG renders the complete
source at its intrinsic 16 x 16 size, and its alpha coverage receives the state
foreground color. The whole glyph cell is centered at (15, 8) in the button;
there are no path transforms, glyph offsets, resampling or gamma adjustments.
The generator pins the SHA-256 of each SVG. It does not read Windows atlases,
resource dumps or either older atlas-based caption generator.

| Palette | Active normal | Inactive normal | Other hot | Other pressed |
| --- | --- | --- | --- | --- |
| NORMAL | 28, 32, 40 | 39, 43, 51 | Normal + 24 per channel | Normal + 14 per channel |
| LIGHT | 238, 238, 238 | 243, 243, 243 | Normal - 24 per channel | Normal - 14 per channel |

Normal and disabled backgrounds match the corresponding actual frame-caption
interior colors. Close hot uses RGB (196, 43, 28), close pressed uses
(176, 39, 25), and both use a white icon in either palette. NORMAL icons are
white when active or hovered, (160, 160, 160) when inactive normal, and
(109, 109, 109) when disabled. LIGHT icons are black when active or hovered,
(95, 95, 95) when inactive normal, and (146, 146, 146) when disabled. The flat
backgrounds have no bevel, border, highlight ring, gradient or shadow.

Run `PYTHONDONTWRITEBYTECODE=1 python3 test_captionbuttons_fluent.py` to read the
actual BMP headers and pixels, verify all eight states against native SVG
coverage, check frame-background equality and state colors, and verify a
repeat generation leaves the checked-in bytes and modification times intact.
This host asset check does not establish Windows 11 or guest rendering parity.
