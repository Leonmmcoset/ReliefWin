# Flat frame surfaces

`frames.py` generates the NORMAL and LIGHT frame surfaces directly with Pillow.
It reads no Windows resources, atlas, dump, screenshot or external image. Run
`PYTHONDONTWRITEBYTECODE=1 python3 frames.py` in this directory, or pass an
existing output directory. `--check` compares all 18 actual BMP files without
writing. Matching files are not rewritten during generation.

The frame dimensions, two-state vertical layout and opaque RGB BMP format are
preserved. Active/inactive body colors remain (28, 32, 40)/(39, 43, 51) for
NORMAL and (238, 238, 238)/(243, 243, 243) for LIGHT. Every pixel of each state
uses that state's body color, including the outermost rows and columns. All
explicit dark, black, white and bright outlines are removed. No resize metric,
hit region, sizing margin or INI is changed.

| Surface | Per-state dimensions |
| --- | --- |
| FRAMECAPTION | 8 x 30 |
| SMALLFRAMECAPTION | 8 x 22 |
| FRAMECAPTIONMIN | 8 x 30 |
| FRAMELEFT | 6 x 8 |
| FRAMERIGHT | 6 x 8 |
| FRAMEBOTTOM | 8 x 6 |
| FRAMECAPTIONSIZING | 40 x 20 |
| SMALLFRAMECAPTIONSIZING | 40 x 20 |
| FRAMEMAXIMIZED | 8 x 30 |

Tool windows use SMALLFRAMECAPTION and reuse FRAMELEFT, FRAMERIGHT and
FRAMEBOTTOM through their SmallFrame sections. Maximized captions and sizing
templates already contain no outlines, so their generated bytes remain
unchanged. The regular caption button assets are separate and are not touched.

Run `PYTHONDONTWRITEBYTECODE=1 python3 test_frames.py` for actual-pixel checks of
all 18 surfaces, all normal/maximized/minimized/tool-window consumers in the
three theme INIs, deterministic generation and rejection of damaged or missing
assets. The test verifies every pixel against the uniform state body color,
rather than only scanning for exact white. This host check does not
establish actual guest window rendering or Windows 11 parity.
