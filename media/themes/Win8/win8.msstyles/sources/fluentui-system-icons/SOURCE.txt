The SVG files are preserved unmodified. captionbuttons_fluent.py uses the
16-pixel regular Dismiss, Subtract, Square and Square Multiple assets at their
native size, centered as complete 16 x 16 cells in 46 x 32 caption buttons.
No path or glyph is translated, scaled, clipped, overlaid, gamma-adjusted or
otherwise changed. Raster alpha coverage receives only the theme's state
colors. In particular, the minimize glyph is not moved toward the baseline.
The regular Subtract source is byte-identical to the existing shellframe icon
from this same recorded upstream revision. The older filled Subtract and
12-pixel Dismiss sources remain available for their existing consumers.
